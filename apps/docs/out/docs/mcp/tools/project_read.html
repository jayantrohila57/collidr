project_read

MCP tool for the project.read action.

MCP tool
project_read
Canonical action
project.read
Description
Read project
OAuth scopes
mcp:toolsprojects:read
Org roles
owner, manager, member
Project grant
May require grant

Input (JSON)

Validated with Zod in @loftlancer/api/mcp. Organization context uses organizationId or organizationSlug (MCP tokens do not carry an active-org cookie).

{
  "$ref": "#/definitions/project_read",
  "definitions": {
    "project_read": {
      "type": "object",
      "properties": {
        "organizationId": {
          "type": "string",
          "minLength": 1
        },
        "organizationSlug": {
          "type": "string",
          "minLength": 1
        },
        "id": {
          "type": "string",
          "format": "uuid"
        },
        "slug": {
          "type": "string",
          "minLength": 1
        }
      },
      "additionalProperties": false
    }
  },
  "$schema": "http://json-schema.org/draft-07/schema#"
}

Example request

{
  "name": "project_read",
  "arguments": {}
}

Output

The MCP server returns a single text content block whose body is pretty-printed JSON from the underlying studio tRPC caller (runMcpTool in @loftlancer/api/mcp). Errors surface as tool errors (for example insufficient_scope, organization_required, or validation messages).
