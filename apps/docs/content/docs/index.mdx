Loftlancer is a multi-tenant workspace for teams. Each project installs [apps](/docs/concepts/apps): **Environments** (encrypted variables with `.env` import/export) and **Tasks**. Permissions run through canonical **actions** in `@loftlancer/actions`, with an audit timeline and notifications.

This site is **fully public** (no sign-in required to read docs). Use the header to open **Studio** or **Sign in** when you have an account.

## How it is deployed

One domain, three Next.js apps behind path routing:

| Path | App | Role |
| --- | --- | --- |
| `/` | `apps/docs` | Landing, pricing and this documentation |
| `/auth` | `apps/auth` | Sign-in (GitHub via Better Auth), account settings, OAuth consent and device sign-in |
| `/studio` | `apps/studio` | Signed-in dashboard: organizations, projects and their [apps](/docs/concepts/apps) |

Projects live at `/studio/p/<slug>`.
