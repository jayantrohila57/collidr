Env Manager is a multi-tenant dashboard for organizing **environment variables** with encryption at rest, canonical **actions** for permissions, and optional audit timeline and notifications.

This site is **fully public** (no sign-in required to read docs). Use the header links to open the product **Studio** or **Sign in** when you have an account.

## What you will find here

- **Getting started** — concepts and local development pointers
- **API overview** — how the product API is structured today (`apps/web` tRPC)
- **MCP** — planned tool surface, OAuth scopes, and mapping to `@env-manager/actions`

## Platform direction

The monorepo is splitting into dedicated apps (`auth`, `studio`, `account`, `docs`, `mcp`, `console`). See the [platform plan](https://github.com/jayantrohila57/env-manager/blob/main/docs/PLAN_PLATFORM_APPS.md) for hostnames and migration steps.
