Env Manager is a multi-tenant workspace for **environment variables** with encryption at rest, canonical **actions** in `@env-manager/actions`, and optional audit timeline and notifications.

This site is **fully public** (no sign-in required to read docs). Use the header to open **Studio** or **Sign in** when you have an account.
