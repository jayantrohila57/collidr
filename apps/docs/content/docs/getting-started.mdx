## Prerequisites

- Node.js 20+
- pnpm 10.13.1 (Corepack)
- PostgreSQL (`DATABASE_URL`)
- GitHub OAuth credentials

## Run the studio locally

From the repository root:

```bash
pnpm install
# configure apps/web/.env — see README.md
pnpm dev:web
```

The dashboard runs at `http://localhost:3000`.

## Run marketing and docs

```bash
pnpm --filter www dev    # http://localhost:3006
pnpm --filter docs dev   # http://localhost:3001 → /docs
```
