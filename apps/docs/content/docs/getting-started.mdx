## Prerequisites

- Node.js 20+
- pnpm 10.13.1 (Corepack)
- PostgreSQL (`DATABASE_URL`)
- GitHub OAuth credentials

## Run the studio locally

From the repository root:

```bash
pnpm install
# configure env per app — see README.md and docs/PRODUCTION_DEPLOY.md
pnpm --filter studio dev
```

Studio runs at `http://localhost:3000` (or the port shown in the terminal).

## Run docs and other apps

```bash
pnpm --filter docs dev   # http://localhost:3001 → /docs
pnpm --filter auth dev   # auth app (OAuth callbacks)
pnpm --filter console dev
```
