---
title: Tasks
description: Track work inside a project with the Tasks app.
---

The **Tasks** app adds a task list to a project at `/studio/<org>/<project>/tasks`. Install it first from the project's **Apps** page (see [Apps](/docs/concepts/apps)).

## What a task has

- A number unique within the project
- Status, priority, assignee, due date and labels
- Comments

Assignees and people mentioned in comments get in-app [notifications](/docs/guides/notifications).

## Actions

| Action | Use |
| --- | --- |
| `tasks.task.read` | View tasks |
| `tasks.task.create` | Create tasks |
| `tasks.task.update` | Edit status, assignee and other fields |
| `tasks.task.delete` | Delete tasks |
| `tasks.comment.create` | Comment on tasks |

Tasks are not available as MCP tools.
